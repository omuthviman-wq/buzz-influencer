# バズれ！AIインフルエンサー

AIインフルエンサーを30日で育てる、スマホだけで遊べるゲームです。
サーバーもパソコンも要りません。`index.html` 1ファイルで動きます。

## あそびかた

- 最初に自分のインフルエンサーを作ります（アイコン・名前・ジャンル・性格）
- 毎日「今日の方針」を決めます（テーマ＝トレンドなど／トーン＝まじめ・エモい・ネタ・お役立ち・攻める）
- 投稿の文章はAIがキャラになりきって自分で書きます。バズり度に応じてフォロワーが増えます
- 攻めた投稿ほど炎上しやすくなります。炎上したら謝罪投稿で鎮火させましょう（誠実さもAIが判定）
- 投稿すると元気が減ります。休むと回復します
- フォロワーが増えると企業案件が来ます。キャラに合わない案件を受けると好感度が下がります
- 稼いだお金でショップのアイテム（リングライト・プロ編集者など）を買えます
- ライバル4人（ミナミ・レン・ぽてと・ケンジ社長）も毎日投稿します。30日目にランキング1位を目指しましょう

## 必要なもの

- GeminiのAPIキー（無料）: https://aistudio.google.com/apikey
  - 支払い設定をしていないプロジェクトのキーなら課金されません。回数制限に達するとしばらく投稿できなくなるだけです
  - 投稿1回につきAPIを1回呼びます（休む・ショップはAPIを使いません）
- APIキーとセーブデータは、そのスマホのブラウザの中（localStorage）にだけ保存されます

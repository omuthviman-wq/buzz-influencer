# 今夜も配信中

スマホだけで遊べる、ライブ配信×恋愛シミュレーションゲームです（Gemini API・無料枠でOK）。

**遊ぶ: https://omuthviman-wq.github.io/buzz-influencer/**

## あそびかた

- あなたは駆け出しの配信者。配信ではリスナーのコメントをタップして拾い、自分の言葉で返します（方針を選んでおまかせもOK）
- 返しがウケると同接と登録者が増えます。スパチャも飛んできます
- ヒロインは4人
  - 🐰 みゆ … 初配信から見ている常連リスナー
  - 🦋 レイカ … 登録者30万人の人気配信者（先輩）
  - 🌻 ひより … デビューしたての新人配信者（後輩）
  - 🐈‍⬛ 黒猫 … 正体不明の高額スパチャ。その正体は…？
- DM（選択肢 or 自由入力）、コラボ配信、プレゼント、デートで仲が深まります
- 好感度が上がるとデート、そして告白。恋人になれることも
- デートを誰かに見られると熱愛疑惑…次の配信でガチ恋勢が離れていきます
- 30日目にエンディング。恋の結末をAIがエピローグに書いてくれます
